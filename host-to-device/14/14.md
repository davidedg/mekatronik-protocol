# `14` - Select the active profile

| bmRequestType | bRequest | wValue | wIndex | wLength |
|---|---|---|---|---|
| `40` | `14` | profile, `0001` to `0003` | `0000` | `0000` |

Makes the profile the active one, as its profile key on the keyboard does. Seen: the Windows software sends it when one of its PROFILE pages is clicked, and as the last request of every profile write (for the profile it wrote).

- The keyboard sends no notification when the host selects a profile (the profile keys do: [`81`](../../device-to-host/81/81.md) `f1` to `f3`).
- [`1a`](../1a/1a.md) applies to the active profile, so select the profile before setting its Instant Shift keys.
- Read the active profile with [`15`](../15/15.md) or byte 7 of [`04`](../04/04.md).
- After it the keyboard sends empty key reports on [`81`](../../device-to-host/81/81.md) and [`83`](../../device-to-host/83/83.md) (all keys released).
