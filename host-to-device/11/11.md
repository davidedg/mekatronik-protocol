# `11` - Read the macro index

| bmRequestType | bRequest | wValue | wIndex | wLength |
|---|---|---|---|---|
| `c0` | `11` | `0000` | profile, `0001` to `0003` | `0069` |

Reply: the 105-byte [macro index](../../formats/macro-index.md) of the profile, as written with [`10`](../10/10.md).

The vendor software does not read it; in tests it answered for all three profiles. A profile that was never written answers 105 bytes of `ff`.

**Read the index before reading the macro data** ([`13`](../13/13.md)): its bytes 3 to 4 give the length to ask for, and an index of `ff` means there is no data to read.
