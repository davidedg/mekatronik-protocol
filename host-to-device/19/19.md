# `19` - Read the key matrix

| bmRequestType | bRequest | wValue | wIndex | wLength |
|---|---|---|---|---|
| `c0` | `19` | `0000` | profile, `0001` to `0003` | `00a0` |

Reply: the 160-byte [key matrix](../../formats/matrix.md) of the profile, as written with [`18`](../18/18.md). The vendor software does not read it; in tests it answered for all three profiles, also for profiles that were never written (they hold the default matrix).
