# `18` - Write the key matrix

| bmRequestType | bRequest | wValue | wIndex | wLength |
|---|---|---|---|---|
| `40` | `18` | `0000` | profile, `0001` to `0003` | `00a0` |

Data: the 160-byte [key matrix](../../formats/matrix.md) of the profile: the code each key position produces in Game mode. Remaps and the choice of T13 to T20 are written here.

The vendor software sends it first in every profile write. Read back with [`19`](../19/19.md).
