# `1a` - Instant Shift keys

| bmRequestType | bRequest | wValue | wIndex | wLength |
|---|---|---|---|---|
| `40` | `1a` | `hh ll` | `0000` | `0000` |

Sets the **Instant Shift System** of the **active profile** p (the one selected with [`14`](../14/14.md)): while a modifier is held, the T keys run the macros of another profile.

| Byte of wValue | Meaning |
|---|---|
| low (`ll`) | modifier that reaches profile p+1 |
| high (`hh`) | modifier that reaches profile p+2 |

Profiles count cyclically (after 3 comes 1). Modifiers are HID usages: `e0` left Ctrl, `e1` left Shift, `e2` left Alt; `00` none. The vendor software lets each modifier be used once per profile.

| Active profile | Setting | wValue |
|---|---|---|
| 1 | Shift → profile 2 | `00e1` |
| 1 | Shift → profile 2, Ctrl → profile 3 | `e0e1` |
| 2 | Shift → profile 3, Alt → profile 1 | `e2e1` |
| any | none (vendor "Reset") | `0000` |

Seen: the vendor software sends it in every profile write, after the tables and before the final `14` of that profile; for profile 2 it also sent `14 0002` first.

With Ctrl → profile 3 on profile 1, and T8 of profile 3 set to type X:

```
Normal mode, boot report (81):
01 00 f3 00 00 00 00 00   Ctrl pressed: Ctrl reaches the host, and the notification "profile 3"
00 00 1b 00 00 00 00 00   T8 pressed: X, without Ctrl
00 00 f1 00 00 00 00 00   Ctrl released: back to profile 1

Game mode: Ctrl as modifier 01 on the NKRO report (83) and f3 on the boot report, X on the NKRO report with
modifiers 00, then f1.
```

- **Instant Shift works in Normal and in Game mode.**
- **The modifier also reaches the host** while it is held, but the firmware leaves it out of the reports of the shifted key: the computer gets "x", not Ctrl+X.
- The firmware looks at the code a key produces: Scroll Lock remapped to left Ctrl ([matrix](../../formats/matrix.md)) triggered the shift too.
- Each profile keeps its own setting *(inferred: the request carries no profile number, and the vendor software keeps one setting per profile and always selects the profile first)*.
- Not known: whether the right-hand modifiers (`e4` to `e6`) work.
