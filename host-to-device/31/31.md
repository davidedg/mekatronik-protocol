# `31` - Backlight of a zone

| bmRequestType | bRequest | wValue | wIndex | wLength |
|---|---|---|---|---|
| `40` | `31` | `pp ll` | zone, plus `80` when off | `0000` |

Sets the light of one zone. The vendor software sends four requests, one per zone, about 0.26 s apart, in the order of its settings file (`WASDLIGHT`, `DIRECTLIGHT`, `NUMBERLIGHT`, `Tt`; [vendor files](../../formats/vendor-files.md)).

| wIndex | Zone | Lit keys on the test unit |
|---|---|---|
| `0000` / `0080` | 0, WASD: on / off | W, A, S, D, left Shift, left Ctrl, Space |
| `0001` / `0081` | 1, arrows: on / off | the four arrow keys and keypad 8, 4, 5, 6 |
| `0002` / `0082` | 2, numeric keypad: on / off | no visible effect on the test unit |
| `0003` / `0083` | 3, Tt logo: on / off | the logo |

No other key of the test unit is ever lit (T, Y, U, the digits, ...).

| wValue | Light |
|---|---|
| `0000` | level I (dimmest) |
| `0001` | level II |
| `0002` | level III |
| `0003` | level IV (brightest) |
| `0104` | Pulse: the zone fades from off to full and back, about 10 s per cycle |

The low byte is the level (0 to 3, or 4 for pulse), the high byte is `01` with pulse. A zone that is off gets wIndex `80` + zone; its wValue still carries the pulse flag when Pulse is chosen (`0100`), and is `0000` otherwise.

Seen, from the Light Option page of the vendor software ("Apply"):

| Settings | Requests (wValue wIndex) |
|---|---|
| level I, zones 0 to 2 on, logo off | `0000 0000`, `0000 0001`, `0000 0002`, `0000 0083` |
| level II, the same | `0001 0000`, `0001 0001`, `0001 0002`, `0000 0083` |
| level III, the same | `0002 0000`, `0002 0001`, `0002 0002`, `0000 0083` |
| level IV, the same | `0003 0000`, `0003 0001`, `0003 0002`, `0000 0083` |
| Pulse, the same | `0104 0000`, `0104 0001`, `0104 0002`, `0000 0083` |
| Pulse, all on, logo on | `0104 0000`, `0104 0001`, `0104 0002`, `0104 0003` |
| Pulse, only the arrows | `0100 0080`, `0104 0001`, `0100 0082`, `0000 0083` |
| Pulse, only WASD | `0104 0000`, `0100 0081`, `0100 0082`, `0000 0083` |

The keyboard's light followed each change; the software then shows the level on screen.

At start, the software sends its saved setting again, but translates Pulse differently: with `LIGHTSTYLE=0` (Pulse) it sent `0000` for the zones that are on and `0100` with wIndex `80`+zone for those that are off. With a level it sends the same as its Light Option page (`LIGHTSTYLE=1` → `0000`, `LIGHTSTYLE=4` → `0003`). The setting is global, not per profile: no profile write sends it.

The backlight key of the keyboard also changes the level of the zones and is [notified](../../device-to-host/81/81.md) (`fa` to `fe`); [`04`](../04/04.md) reports the levels.

Not known: whether the firmware keeps the setting after a power cycle (the vendor software resends it at every start).
