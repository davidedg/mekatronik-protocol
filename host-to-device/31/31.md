# `31` - Backlight of a zone

| bmRequestType | bRequest | wValue | wIndex | wLength |
|---|---|---|---|---|
| `40` | `31` | setting | zone, plus `80` when off | `0000` |

For the **Illuminated** edition, which has three backlit zones and a lit logo. **The test unit has no zone lights** (only white backlight on fixed keys, driven by the backlight key), so the effect could not be seen: what follows is what the Windows software sends.

It sends four requests, one per zone, about 0.26 s apart, in the order of its settings file (`WASDLIGHT`, `DIRECTLIGHT`, `NUMBERLIGHT`, `Tt`; [vendor files](../../formats/vendor-files.md)):

| wIndex | Zone |
|---|---|
| `0000` / `0080` | WASD keys, on / off |
| `0001` / `0081` | arrow keys, on / off |
| `0002` / `0082` | numeric keypad, on / off |
| `0003` / `0083` | Tt logo, on / off |

Seen:

| When | Settings | Requests (wValue wIndex) |
|---|---|---|
| Light Option page, "Apply" | Pulse; WASD, arrows, keypad on; logo off | `0104 0000`, `0104 0001`, `0104 0002`, `0000 0083` |
| start of the software | the same settings saved (`LIGHTSTYLE=0`) | `0000 0000`, `0000 0001`, `0000 0002`, `0000 0083` |
| start of the software | `LIGHTSTYLE=1`, zones on, logo off | `0000 0000`, `0000 0001`, `0000 0002`, `0000 0083` |
| start of the software | defaults it created (`LIGHTSTYLE=4`, all on, logo on) | `0003 0000`, `0003 0001`, `0003 0002`, `0104 0003` |
| start of the software | all zones and logo off | `0100 0080`, `0100 0081`, `0100 0082`, `0000 0083` |

- The low byte of wValue looks like the level and `01` in the high byte like pulse: Pulse gives `0104`, the logo "on" too. The levels of the other settings have not been captured from the Light Option page yet.
- The software does not send the same values at start as from its Light Option page for the same saved setting (`0000` instead of `0104` for Pulse).
- It sends the lights at start and from the Light Option page only, not in a profile write: the setting is not per profile.

Not known: the other levels, whether the firmware keeps the setting after a power cycle (the vendor software resends it at every start), and what [`04`](../04/04.md) bytes 4 to 6 show on an Illuminated unit.
