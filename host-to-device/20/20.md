# `20` - Firmware information

| bmRequestType | bRequest | wValue | wIndex | wLength |
|---|---|---|---|---|
| `c0` | `20` | `0000` | `0000` | `0010` |

Reply, 16 bytes. Seen:

```
52 53 30 03 01 35 38 00 c0 00 00 64 00 a0 01 00

offset  size  field
0       2     52 53: the product ID 5253
4       2     01 35: firmware version 1.35, the same as bcdDevice in the device descriptor
other         not known
```

The vendor software does not read it. A host can use bytes 0 to 5 to check that it talks to the firmware these pages describe before writing.
