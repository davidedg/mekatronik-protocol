# `82` - Consumer report and program launch

Interface 1, interrupt IN endpoint `0x82`, 4 bytes: two 16-bit consumer usages, little-endian ([descriptor](../../lsusb/060b/5253/0135)). All zero when released.

| Bytes | Event |
|---|---|
| `e2 00 00 00` | mute |
| `b6 00 00 00` | previous track |
| `cd 00 00 00` | play/pause |
| `b5 00 00 00` | next track |
| `b7 00 00 00` | stop |
| `e9 00 00 00` | volume up |
| `ea 00 00 00` | volume down |
| **`fd kk 00 00`** | **launch**: macro key number `kk` (from 1) has a launch function ([macro data](../../formats/macro-data.md#launch)) |

```
T3 with "Launch Prgm":
fd 03 00 00
00 00 00 00
```

The keyboard stores no program: the host decides what a launch key starts. On Windows the vendor software starts the program saved for the key. To the operating system the report is consumer usage `0x03fd` (for T3), which has no standard meaning; a host program reads it from hidraw.
