# `83` - NKRO keyboard report

Interface 2, interrupt IN endpoint `0x83`, 15 bytes ([descriptor](../../lsusb/060b/5253/0135)):

```
offset  field
0       modifiers: bit 0 left Ctrl, 1 left Shift, 2 left Alt, 3 left GUI, 4 to 7 the right ones
1..14   one bit per key usage 00 to 6f: byte 1 + (usage / 8), bit (usage % 8)
```

```
00 10 00 00 ...   A (04: byte 1, bit 4)
00 20 00 00 ...   B (05: byte 1, bit 5)
01 00 00 00 ...   left Ctrl
```

In **Game mode** the keyboard types on this report, keys and macros alike; in Normal mode it uses the boot report [`81`](../81/81.md), macros included. In Game mode the left Windows key sends nothing (the right one was not tried).

Only usages up to `6f` fit in the bitmap: a key remapped to a usage above it (the international keys `85` to `91`) cannot be typed in Game mode *(inferred from the descriptor)*.

**A T key of a profile that was never written** (macro index all `ff`) sent about 26 000 empty reports at 1 ms intervals (37 s) and blocked the other macros meanwhile ([behaviour](../../devices/meka-g-unit.md#behaviour)).
